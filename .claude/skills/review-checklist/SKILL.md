# レビューチェックリスト（review-checklist）

詳細な項目は同じディレクトリの `checklist.md` にある。**レビューを始める前に `checklist.md` を読む**こと。

## 使い方

1. 差分と、対応する仕様（AC 一覧）を用意する。
2. `checklist.md` の各章を上から順に確認し、該当しない章は「対象外」と明記して飛ばす。
3. 指摘は「Critical / Major / Minor / Nit」で分類する（定義は `reviewer` サブエージェントに準拠）。
4. 確認できなかった項目は「未確認」と書く。推測で OK にしない。

## 重大度の目安

- **Critical**: データ破壊・情報漏えい・認可抜け・仕様違反・本番で確実に壊れる不具合 → マージ不可
- **Major**: 一部条件で壊れる、テスト不足、保守性を大きく損なう設計 → 直してからマージ
- **Minor**: 読みやすさ・小さな重複 → 次のタスクで対応可
- **Nit**: 好みの範囲 → 任意
