次の要望から仕様書を作成してください。

要望: $ARGUMENTS

1. スキル `spec-writing` の手順に従う。
2. `docs/specs/` の既存ファイルを確認して次の連番 `NNNN` を決め、`docs/specs/_template.md` をコピーして `docs/specs/NNNN-<slug>.md` を作る。
3. 要望から読み取れない点（対象ユーザー、異常系、データの扱い、非機能要件）は**推測で埋めず**、「未決事項」に書くか、人間に質問する。
4. 受け入れ条件は `AC-1` から連番で、Given / When / Then の形にし、テストに直訳できる粒度にする。
5. 完成したら、仕様の要約と未決事項を提示して**人間の承認を求める**。承認前に計画や実装へ進まない。
