# 0007: ページネーション

- Status: approved
- 作成日: 2026-10-07
- Issue: #7
- 関連: `0001-github-repo-search.md`（親仕様）、依存: 0004, 0006

## 1. 背景と目的
検索結果のページを移動できるようにする。GitHub検索APIは上位1,000件までしか返さないため、その上限と、範囲外のページを開いた場合も扱う。

## 2. 対象ユーザーと前提
- ロール: 閲覧者。ログイン不要。
- 前提: 0006（検索結果一覧）が完了している。1ページ30件。最大ページ数は0004の関数で計算する。

## 3. ユーザーストーリー
- 閲覧者として、検索結果を前後のページへ移動して見られる。それは多数の結果から探しやすくするためである。
- 閲覧者として、存在しないページを開いたときに案内が出る。それは行き止まりで迷わないためである。

## 4. 範囲
### 4.1 やること
- ページネーションのコンポーネント（前へ・次へ・ページ番号）
- 最大ページ数の計算結果の利用（0004の関数）
- 範囲外ページの案内表示
- 1,000件を超える場合の注記

### 4.2 やらないこと（Non-goals）
- 無限スクロール
- 件数・並び順の変更UI

## 6. 画面・API の契約
### 6.1 画面（該当する場合）
- URL: `/?q=<keyword>&page=<n>`
- 表示要素: 一覧の下にページネーション。1,000件超のときは注記。
- 状態: 通常 / 範囲外ページ（案内と導線）。ページ番号が多いときは省略表示。
- 文言と表示の前提（仕様で定める）:
  - ナビゲーションは `nav`（ラベル「ページネーション」）。「前へ」「次へ」。現在ページの前後2ページを表示（固定）し、先頭と末尾は常に表示する。
  - 1,000件超の注記: 「上位1,000件まで表示します」（総件数が1,000を超えるときだけ。ちょうど1,000では出さない）。
  - 範囲外の案内: 「指定されたページは存在しません」。導線は、AC-9bでは「先頭のページへ」（`page=1`）、AC-9cでは「最終ページ（{n}ページ目）へ」。
  - 範囲外のとき（AC-9b・9c）は、検索フォームと案内・導線だけを表示し、総ヒット件数・一覧・ページネーションは表示しない。
  - 「前へ」「次へ」が押せない状態は、遷移する `a`（`href`）にせず、`role="link"` と `aria-disabled="true"` を持つ要素（`href`・`tabindex` なし）で表す（`aria-disabled` はロールを持つ要素にだけ有効で、ロールのない `span` では支援技術に伝わらないため。MDN の `aria-disabled` の対応ロールに `link` が含まれる）。
- 範囲外の判定: `page` が34を超えるとき（`calculateMaxPage(SEARCH_RESULT_LIMIT)`）は、APIを呼ばずに範囲外（AC-9b）。34以下で、APIが返した総件数が1以上かつ `page` が `calculateMaxPage(総件数)` を超えるときは範囲外（AC-9c）。総件数が0のときは `page` に関わらず範囲外にしない（AC-9d）。

### 6.2 API・Server Action（該当する場合）
検索APIは上位1,000件までしか返さない。`per_page=30` のとき、`page` が34を超える指定は422になるため、34を超える場合はAPIを呼ばない。

## 7. データ
保存はしない。ページ番号はURLのクエリ `page` で表す。

## 8. 非機能要件
- アクセシビリティ: ナビゲーションとして識別でき（`nav`、ラベル）、現在ページが支援技術に伝わる。キーボードで操作できる。
