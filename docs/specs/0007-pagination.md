# 0007: ページネーション

- Status: draft
- 作成日: 2026-10-07
- Issue: なし（リポジトリ作成前。起票後に記入）
- 関連: `0001-github-repo-search.md`（親仕様）、依存: 0004, 0006

## 1. 背景と目的
検索結果のページを移動できるようにする。GitHub検索APIは上位1,000件までしか返さないため、その上限と、範囲外のページを開いた場合も扱う。

## 2. 対象ユーザーと前提
- ロール: 閲覧者。ログイン不要。
- 前提: 0006（検索結果一覧）が完了している。1ページ30件。最大ページ数は0004の関数で計算する。

## 3. ユーザーストーリー
- 閲覧者として、検索結果を前後のページへ移動して見られる。それは多数の結果から探しやすくするためである。
- 閲覧者として、存在しないページを開いたときに案内が出る。それは行き止まりで迷わないためである。

## 4. 範囲
### 4.1 やること
- ページネーションのコンポーネント（前へ・次へ・ページ番号）
- 最大ページ数の計算結果の利用（0004の関数）
- 範囲外ページの案内表示
- 1,000件を超える場合の注記

### 4.2 やらないこと（Non-goals）
- 無限スクロール
- 件数・並び順の変更UI

## 6. 画面・API の契約
### 6.1 画面（該当する場合）
- URL: `/?q=<keyword>&page=<n>`
- 表示要素: 一覧の下にページネーション。1,000件超のときは注記。
- 状態: 通常 / 範囲外ページ（案内と導線）。ページ番号が多いときは省略表示。

### 6.2 API・Server Action（該当する場合）
検索APIは上位1,000件までしか返さない。`per_page=30` のとき、`page` が34を超える指定は422になるため、34を超える場合はAPIを呼ばない。

## 7. データ
保存はしない。ページ番号はURLのクエリ `page` で表す。

## 8. 非機能要件
- アクセシビリティ: ナビゲーションとして識別でき（`nav`、ラベル）、現在ページが支援技術に伝わる。キーボードで操作できる。
