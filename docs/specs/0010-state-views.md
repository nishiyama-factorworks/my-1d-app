# 0010: 状態表示（読み込み中・0件・エラー・404）

- Status: draft
- 作成日: 2026-10-07
- Issue: なし（リポジトリ作成前。起票後に記入）
- 関連: `0001-github-repo-search.md`（親仕様）、依存: 0006, 0008

## 1. 背景と目的
検索・詳細で起こりうる各状態（読み込み中、0件、エラー、存在しないリポジトリ）を、利用者に分かる形で表示する。

## 2. 対象ユーザーと前提
- ロール: 閲覧者。ログイン不要。
- 前提: 0006（一覧）と0008（詳細）が完了している。エラーの種別は0003で分類済み（`RATE_LIMIT` `NOT_FOUND` `VALIDATION` `UPSTREAM` `NETWORK`）。

## 3. ユーザーストーリー
- 閲覧者として、読み込み中であることが分かる。それは待っている間に不安にならないためである。
- 閲覧者として、結果が0件のときに、その旨と次の行動が分かる。それは別のキーワードで探し直すためである。
- 閲覧者として、エラーが起きたときに、原因の目安と再試行の方法が分かる。それは自分で復旧できるようにするためである。

## 4. 範囲
### 4.1 やること
- 検索結果・詳細の読み込み中表示
- 検索結果0件の表示
- エラー種別ごとの表示（レート制限、その他のAPIエラー、ネットワークエラー）と、再試行の導線
- 存在しないリポジトリの404表示

### 4.2 やらないこと（Non-goals）
- エラーの分類そのもの（0003）
- 範囲外ページの案内（0007）

## 5. 受け入れ条件（テストに直訳できる粒度で）

| ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-16a | 検索結果の取得に時間がかかっている | 待機中の画面を表示する | 読み込み中であることが分かる表示（ローディング）が出る |
| AC-16b | 詳細の取得に時間がかかっている | 待機中の画面を表示する | 読み込み中であることが分かる表示が出る |
| AC-17 | キーワード `zzzxqy` の検索で `total_count=0` | 一覧を表示する | 「見つかりませんでした」と、検索したキーワード `zzzxqy`、別のキーワードを試すよう促す文言が表示される |
| AC-18a | `RATE_LIMIT`（リセット時刻あり）で失敗する | 画面を表示する | レート制限に達したことと、リセット時刻が表示される |
| AC-18b | `RATE_LIMIT`（リセット時刻なし）で失敗する | 画面を表示する | レート制限に達したことと、しばらくしてから再試行するよう促す文言が表示される |
| AC-19a | `UPSTREAM` または `VALIDATION` で失敗する | 画面を表示する | エラーが起きたことが分かる表示と、再試行の導線が出る |
| AC-19b | `NETWORK` で失敗する | 画面を表示する | 接続できなかったことが分かる表示と、再試行の導線が出る |
| AC-19c | `GITHUB_TOKEN` が設定され、いずれかのエラーが起きる | 画面を表示する | 画面にトークン、スタックトレース、APIの生のレスポンスが含まれない |
| AC-19d | エラー表示の画面 | 再試行の導線を操作する | 同じ条件で再取得が行われる |
| AC-20b | `/repos/no-such-owner/no-such-repo`（`NOT_FOUND`） | ページを表示する | 404の専用表示と、トップへ戻る導線が表示される |

## 6. 画面・API の契約
### 6.1 画面（該当する場合）
| 状態 | 対象画面 | 表示内容 |
| --- | --- | --- |
| 読み込み中 | トップ（一覧）、詳細 | ローディング表示 |
| 0件 | トップ | 「見つかりませんでした」、検索キーワード、別のキーワードを促す文言 |
| レート制限 | トップ、詳細 | 制限に達した旨、リセット時刻（分かる場合）または再試行を促す文言 |
| その他のエラー | トップ、詳細 | エラーの旨、再試行の導線 |
| 404 | 詳細 | 404の専用表示、トップへ戻る導線 |

### 6.2 API・Server Action（該当する場合）
該当なし。0003のエラー種別を表示に対応づける。

## 7. データ
保存はしない。

## 8. 非機能要件
- セキュリティ: 内部情報（トークン、スタックトレース、APIの生のレスポンス）を画面に出さない。
- アクセシビリティ: 状態メッセージが支援技術に伝わるようにする（詳細は0011）。
