# 0005: 検索フォーム

- Status: draft
- 作成日: 2026-10-07
- Issue: なし（リポジトリ作成前。起票後に記入）
- 関連: `0001-github-repo-search.md`（親仕様）、依存: 0004

## 1. 背景と目的
トップページに、キーワードを入力して検索を実行するフォームを作る。検索結果の取得・表示は0006で行うため、この時点では結果を表示しない。

## 2. 対象ユーザーと前提
- ロール: 閲覧者。ログイン不要。
- 前提: 0004の関数（キーワードの正規化、検索パス生成）が使える。

## 3. ユーザーストーリー
- 閲覧者として、キーワードを入力して検索できる。それは目的のリポジトリを探すためである。
- 閲覧者として、何も入力せずに検索したときに、入力を促す案内が出る。それは操作を間違えても迷わないためである。

## 4. 範囲
### 4.1 やること
- トップページ（`/`）のタイトル表示と検索フォーム
- 送信時のURL遷移
- 空入力時の案内表示
- URLの `q` を入力欄の初期値に反映

### 4.2 やらないこと（Non-goals）
- 検索結果の取得・表示（0006）
- ページネーション（0007）
- 読み込み中・エラー表示（0010）

## 5. 受け入れ条件（テストに直訳できる粒度で）

| ID | Given | When | Then |
| --- | --- | --- | --- |
| AC-1 | トップページ（`/`） | 表示する | ラベル付きのキーワード入力欄と、「検索」ボタンがある |
| AC-2a | 入力欄に `react` を入力した | 「検索」ボタンを押す | `/?q=react&page=1` へ遷移する |
| AC-2b | 入力欄に `react` を入力した | 入力欄でEnterキーを押す | `/?q=react&page=1` へ遷移する |
| AC-3a | 入力欄が空（`""`） | 「検索」ボタンを押す | 遷移せず、「キーワードを入力してください」と案内を表示する。APIは呼ばれない |
| AC-3b | 入力欄が空白のみ（`"   "`） | 「検索」ボタンを押す | AC-3aと同じ結果になる |
| AC-22a | 入力欄に `"  next.js  "`（前後に空白）を入力した | 検索する | `q=next.js`（前後の空白を除いた値）で遷移する |
| AC-22b | 入力欄に `"日本語 & react"` を入力した | 検索する | キーワードが正しくエンコードされたURL（`&` が `%26`）へ遷移する |
| AC-22c | URLが `/?q=react&page=3` | トップページを表示する | 入力欄の初期値が `react` になっている |

## 6. 画面・API の契約
### 6.1 画面（該当する場合）
- URL: `/`
- 表示要素: アプリのタイトル（仮の定数）、ラベル付き入力欄、「検索」ボタン、空入力時の案内
- 状態: 通常 / 空入力の案内（「キーワードを入力してください」）。読み込み中・エラーは0010。

### 6.2 API・Server Action（該当する場合）
該当なし。送信は画面遷移（URLの更新）で行う。

## 7. データ
保存はしない。検索条件はURLのクエリ（`q` `page`）で表す。

## 8. 非機能要件
- アクセシビリティ: 入力欄にラベルを付ける。Enterキーで送信できる。詳細な確認は0011。
- セキュリティ: キーワードはエンコードして遷移先URLに載せる。
