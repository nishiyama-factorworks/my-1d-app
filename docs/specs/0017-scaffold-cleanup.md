## 1. 背景と目的

Create Next App の雛形が残っている（`app/layout.tsx` の `metadata` のタイトルが `Create Next App`、`lang="en"`、`public/` の雛形 SVG）。プロジェクトの実態に合わせる。PR #14 の提案 P4。

## 2. 対象ユーザーと前提

- アプリの利用者（タイトルと言語がブラウザやスクリーンリーダーに伝わる）。
- アプリ名は「GitHub リポジトリ検索」を想定（未決）。

## 3. ユーザーストーリー

- 利用者として、タブのタイトルと言語がアプリの実態に合っていてほしい。それは何のページか分かり、スクリーンリーダーが正しい言語で読み上げるためである。

## 4. 範囲

### 4.1 やること

- `app/layout.tsx` の `metadata` と `lang="en"` を直す。
- `public/` の雛形 SVG（`next.svg`、`vercel.svg`、`file.svg`、`globe.svg`、`window.svg`）のうち、未参照のものを削除する。

### 4.2 やらないこと（Non-goals）

- 検索・詳細などの画面機能
- ファビコンの差し替え
